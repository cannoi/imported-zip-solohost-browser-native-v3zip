## Implemented (code wired)

### Phase 1 — Session lifecycle
- `isPinned` / lease; park skips pinned; sweep closes only after **parked ≥ 2× idle**
- `SESSION_IDLE_MS` floor 2 min, default 10 min
- Park logs `reason`, `idle_ms`
- `ensureHotSlot` skips pinned

### Phase 2 — Agent profile
- Task browser session: `clientKey: 'agent-profile'`, `persist: true` (shared cookies across tasks; still separate tabKey/ledger per task)
- Pin attempt after create via `agentPinned` + lease

### Phase 3 — Search & sources
- Parallel search, ~3.2s timeout, circuit map `searchEngineBlockedMap`
- Outcomes `ok|empty|blocked|error`; **blocked does not navigate to CAPTCHA engine** and does not claim "product unavailable"
- `lib/agent-sources/vn-retail.js` + `compare_products` playbook (direct retailer search URLs)

### Phase 4 (partial)
- Persist debounced off navigate critical path
- Stop forcing all images eager

### Phase 5 (partial)
- `public/live-view.js` **script tag added** — full Live UX still depends on app.js enabling it (not fully driven from UI yet)

## Honest acceptance note
This release **fixes structural causes** of mid-task session kill, search-block false negatives, and cold agent profile.  
It does **not** claim measured 8s→3s page loads or a completed iPhone price matrix on production without a live SoloHost run.
