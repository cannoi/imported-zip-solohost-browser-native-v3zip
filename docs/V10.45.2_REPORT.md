# V10.45.2 — Vietnamese chat IME / encoding fix

## Problem
Typing Vietnamese in AI chat produced broken diacritics (e.g. "điểm chuẩn" → "đâm chuân"), wrong agent queries, mixed-language replies, and frequent geo 429 log spam.

## Root causes addressed
1. **IME composition on Android**: Enter during composition committed half-finished syllables.
2. **Missing NFC normalize**: decomposed Unicode marks not recombined before send/agent.
3. **Lang stuck on `en`**: Agent prompts in English while user wrote Vietnamese → model drift (incl. other languages).
4. **Fonts**: no explicit Vietnamese-capable stack; input under 16px on mobile worsens IME.
5. **geo.lookup_fail 429**: noisy when lookup enabled/rate-limited.

## Fixes
- `#chatInput`: `lang`, `inputmode`, `enterkeyhint=send`, `font-size:16px`, compositionstart/end guards
- `normalizeChatText()` NFC + strip bidi/control; applied in `sendAI` and agent client
- Auto `lang=vi` when message has Vietnamese letters or navigator is `vi*`
- `browser-agent` passes `lang` from task text, not only saved state
- Font stack: Noto Sans Vietnamese / system-ui
- geo failure log at most once/hour
