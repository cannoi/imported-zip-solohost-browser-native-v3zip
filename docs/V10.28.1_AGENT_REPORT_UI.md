# v10.28.1 — Agent completion report UI

## Problem
After agent finished, UI often showed only "✅ Done." User could not see full findings, links, or sources.

## DONE
1. `lib/agent-report.js` — builds structured report (summary, findings, steps, reference links, media, visited pages).
2. On `done`, backend runs `finalizeDoneMessage`: expands short "Done." into full report; keeps long model summaries and appends sources appendix when needed.
3. `done.summary` validation limit raised to 100k characters.
4. Planner prompt requires full report on done (not just the word Done).
5. Client: `renderAgentReportCard` — static card with Expand (blob HTML page) + Copy; markdown headings/lists/code/links/images; steps details.
6. CSS: report body not max-height clipped; links wrap; media grid.

## NOT DONE
- PDF export of report
- Side-by-side compare of two runs
- NOT TESTED ON SOLOHOST with long live agent tasks

## Guardrails
Presentation only — does not change legal/public-data policies of the agent. Users should verify third-party stream or media links themselves.
