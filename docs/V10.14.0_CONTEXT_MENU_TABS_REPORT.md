# SoloHost Browser v10.14.0 — Context Menu & Multi-Tab Report

## Implemented

- Opera-style right-click and 520 ms touch long-press menu for links, images, video/audio and selected text.
- Actions: open link in new tab, open in private tab, copy link/media/text/page URL, share link (or copy when Web Share is unavailable), Google search selected text, open media/image in a new tab, and request link download.
- Private tabs use a unique session identity, do not load/save persistent Playwright storage state, are excluded from persisted tab restore and browsing history; saved tab metadata never includes Bridge tokens/session IDs, and their Bridge session is deleted when closed.
- Tab strip enforces a 12-tab cap and offers a clear toast instead of growing without bound.
- Switching tabs restores the tab's existing Bridge view instead of navigating the site from scratch, reducing redundant reloads. Closing tabs destroys their Bridge session to release engine resources.
- Touch targets and tab strip snapping improved for narrow screens.

## Limitations

- “Share” uses the device/browser Web Share API where available; otherwise it copies the URL. Opera Flow is proprietary and is not integrated.
- Cross-origin downloads may be handled by the system browser and may ignore the `download` hint due to browser security policy.
- Private tabs are isolated from persistent browser storage and history in this app, but this is not a full OS-level private browser; sites can still identify a user by network/IP or account login.
- Some websites use custom canvas/JS hit targets or shadow DOM controls that do not expose a semantic link/media target to the Bridge context menu.
- Live mobile touch testing and multi-tab RAM benchmarking on the user's SoloHost host were not available in this build environment.

## Compatibility

Existing UI modules, Adaptive Layout, Playwright backend, session persistence for regular tabs, Bing default search, auth-policy handoff, AI/Feedback/Settings/Logs and security controls remain. New private-mode behavior is intentionally opt-in per tab.
