# SoloHost Browser v10.26.0 — Browser Agent Upgrade Report

## Summary

Upgraded the server-side Browser Agent from **HTML-snapshot regex observation** to **live Chromium observation**, with safer tools, structured work memory, multi-action steps, and fixed session limits.

## Root causes addressed

| Issue | Fix |
|-------|-----|
| `<form>` regex swallowed inputs | HTML fallback no longer matches `form`; void `input` handled; live observe preferred |
| Observation not live | `lib/engine/observer.js` via `page.evaluate` |
| `maxSteps` capped at 20; `maxMs`/`workMemory` dropped | `start()` accepts `maxSteps` (default 40, max 150), `maxMs`, `workMemory`; disk resume |
| Identical-action loop blocked useful scrolls | State hash (url+elements+scroll); `no_effect` signal; stuck hint in prompt |
| `workMemory` JSON mid-slice | `summarizeWorkMemory()` structured text |
| `fetch_doc` SSRF | `assertPublicHttpUrl` before fetch; redirect caution |
| Search forced DDG | Default **Google**; CAPTCHA → suggest other engines |
| Sensitive false positives | Risk tiers high/medium/low instead of broad SENSITIVE |
| Type+submit without form | Playwright presses **Enter** when no form |
| PDF fake extract | `extractPdfText` + zlib FlateDecode best-effort |

## Architecture (after)

```
UI (poll) → backend-agent → planNext (LLM)
                ↓
         observer.observeLive (Chromium)
                ↓
         executeAction → dom-bridge / playwright-engine
                ↓
         re-observe + diff (no_effect)
```

Engines: **Chromium + Proxy only** (WebKit/Firefox fallbacks removed in 10.25.40).
