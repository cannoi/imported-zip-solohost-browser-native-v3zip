# SoloHost Browser v10.27.0 — Browsing Experience Report

## Goal
Reduce Bridge flicker/scroll-jump and lay foundation for Live (CDP screencast) mode without breaking tabs, agent, AI, noVNC, music, SSRF, access password.

## Phase 1 — Bridge quick wins (DONE)

| Item | Status | Notes |
|------|--------|-------|
| No full iframe reload on click | DONE | `morphBridgeDocument` + `applyBridgeView` fetch HTML and patch/`innerHTML` body; AbortController cancels stale fetches |
| Progress bar | DONE | `#solo-browse-progress` on click/submit |
| Scroll restore | DONE | `data-sh-scroll-y` / `X-SoloHost-Scroll-Y` applied on frame load & morph |
| Scroll → engine | DONE | throttled ~100ms `bridgeEvent({type:scroll})` |
| Form value serialize | DONE | `markInteractive` writes value/checked/selected onto clone |
| Soften CSS | DONE | Removed global `animation:none` / `transition:none`; iOS 16px inputs only in mobile MQ |
| Gzip `/view` | DONE | zlib when `Accept-Encoding: gzip` and body > 1.5KB |
| Smarter navigate settle | DONE | race load vs short timeout (was fixed 260–420ms only) |
| goBack/goForward | DONE | Playwright `page.goBack/goForward` exported |
| Hot pages by RAM profile | DONE | `SOLOHOST_PERF_PROFILE=low\|balanced\|high` → 3/6/10 |

### Measured locally (synthetic, not SoloHost host)

| Metric | Before (code path) | After |
|--------|--------------------|-------|
| Click → iframe `src=` reload | Always (except input) | Morph first; reload only first paint / morph fail |
| Scroll after action | Lost (0 client restore) | Restored from header + body attrs |
| Bridge CSS animations | Forced off | Allowed |
| `/view` payload | Uncompressed | Gzip when client accepts |
| Form value after snapshot | Often empty | Attributes synced from live DOM |

*Network RTT p50 click→frame was not measured on SoloHost hardware in this environment (NOT TESTED ON SOLOHOST).*
