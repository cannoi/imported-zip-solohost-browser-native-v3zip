# SoloHost Browser v10.25.22 — Legacy Website Extraction and Presentation Restoration

## Scope and reference baseline

The request specified v10.20.2 or v10.20.1. Those exact ZIPs were not present among the available project archives. The available older references were v10.20.0 and v10.20.5. To avoid falsely claiming an exact v10.20.1/v10.20.2 match, this release uses the **v10.20.0 `markInteractive(page)` implementation as the exact extraction-function baseline**, while also cross-checking the v10.20.5 archive. The old reference is a source-code baseline, not a claim that all external websites will render pixel-identically.

## Implemented

1. **Restored the original DOM snapshot function.** The complete `markInteractive(page)` function in `lib/engine/playwright-engine.js` was copied byte-for-byte from the available v10.20.0 source. It annotates interactive elements, reads the live DOM, clones the document, removes scripts/noscript/template from the *display copy*, conservatively removes marked ad nodes and untrusted iframe/plugin objects, preserves site classes/stylesheets in the default adaptive/site-style path, and adds the legacy responsive stylesheet. The live Chromium page continues executing scripts, so site interactions still run in the engine.
2. **Removed newer DOM-based family classification from the snapshot method.** The v10.25.21 implementation had added heuristic page-type detection from live DOM signals and broader challenge detection. Those additions are no longer injected into the legacy extraction function. URL-based `classifyPageType()` and the existing content router remain available where the app needs metadata; they do not replace the restored snapshot method.
3. **Restored legacy sanitizer presentation semantics.** Removed the newer `data-sh-page-type` marker injection from `sanitizeHtml()`. The sanitizer continues to preserve site classes and stylesheets, and still applies the existing viewport/responsive stylesheet behavior.
4. **Kept essential newer hardening.** The current sanitizer still removes untrusted `<base>` tags and inserts only a validated HTTP(S) base URL; keeps SoloHost-owned link routing (`target="_self"`, `data-sh-nav`); removes unsafe inline handlers and JavaScript URLs; and restricts embedded frames to the allowlist. These security/link-routing changes were retained intentionally instead of blindly copying an older sanitizer that predates them.
5. **Preserved unrelated features.** Tab-to-Chromium synchronization, opener-scoped popup handling, unowned-page recovery, persistent browser profiles, noVNC login flow, Reader injector, AI features, YouTube/music, audio, and other app features were left in place.
6. **Versioned and documented the result as v10.25.22.** Added a regression test that checks the restored snapshot contract and verifies that tab safety and validated URL handling remain active.

## Files changed intentionally

- `lib/engine/playwright-engine.js` — restore exact v10.20.0 snapshot function; retain newer engine/session fixes.
- `lib/engine/dom-bridge.js` — remove newer page-family marker injection while retaining sanitizer security and link-routing behavior.
- `package.json`, runtime version fallbacks, capability metadata, AI panel metadata, Dockerfile, README and version assertions — version bump to v10.25.22.
- `test-focused-content.js`, `test-adaptive-layout.js` and existing regression tests remain in the suite to protect supported legacy behavior and unrelated features.
- `test-v10.25.21-tab-sync.js` renamed to `test-v10.25.22-tab-sync.js`.
- Added `test-v10.25.22-legacy-extraction.js`.
- Replaced the previous release report with this report so the documentation no longer describes removed/newer extraction behavior as active.

No unrelated source files were deliberately removed in this release. The Static Capture cleanup from v10.25.21 remains in effect; this request restores the legacy live-page DOM extraction/presentation method, not the separate Static Capture feature.

## Not verified in this environment

- The exact v10.20.1 and v10.20.2 source archives were not available, so exact byte-for-byte equivalence to either of those specific releases cannot be asserted. The snapshot function is byte-for-byte identical to the available v10.20.0 reference.
- Playwright was not installed in the test runtime (`playwright_not_installed`), and external DNS resolution failed for `example.com`; therefore a real Chromium end-to-end website render was not exercised here.
- Docker CLI was unavailable, so image build/start was not tested.
- Actual SoloHost/Pi RAM, navigation latency, mobile rendering, login persistence, and multi-tab stress behavior were not measured on target hardware.
- Website behavior depends on site CSP, authentication, scripts, anti-bot challenges, browser compatibility, and third-party resources. This release restores the old extraction/presentation code path but cannot guarantee pixel-identical rendering for every modern website.
