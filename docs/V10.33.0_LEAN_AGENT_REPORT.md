# SoloHost Browser v10.33.0 — Lean Agent

## Architecture (before → after)

**Before:** Long regex chains in AI Panel; short natural questions like "Giá iPhone 18 và nơi nào bán rẻ?" often stayed in **chat** (no Agent). Compare price relied on LLM micro-steps + sequential search engines → CAPTCHA / false "no data". Multiple overlapping state bags (history, workMemory, checklist, ledger).

**After (lean core):**
1. **Intent** (`lib/agent-intent.js` + `classifyUserIntent` in AI Panel): `CHAT` | `QUICK_LOOKUP` | `TASK`
2. **Task Planner**: existing `agent-task-analyzer` + `compare_products` checklist (unchanged contract)
3. **Task Runner**: `lib/agent-runner.js` — bounded parallel jobs (`Promise`-style workers, per-job timeout, partial failure OK)
4. **Evidence reporter**: parallel retail path writes findings + ledger; no invented prices

## Removed / simplified (not deleted whole modules)

| Item | Action |
|---|---|
| `shouldRunAgent` imperative∧hasTarget only | Replaced by `kind === 'TASK'` |
| Sequential 9s×3 search as only path for price tasks | Parallel retailer HTTP fetches first |
| LLM micro-navigation for clear compare_products | Early `runCompareProductsParallel` then return |
