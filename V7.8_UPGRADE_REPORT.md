# SoloHost Browser V7.8.0 — AI Browser report

## Goal
AI as assistant layer only: Search, Summarize, Explain, Translate, Navigate, Extract, Assist.
Browser must work without AI.

## Implemented
- Skill detection + explicit skill parameter from UI chips.
- Hub probe via PERSONAL_AI_HUB_URL / SOLOHOST_AI_HUB_URL.
- Provider order: hub → local Ollama → OpenAI → Anthropic.
- Soft failures (`required: false`) so missing AI never blocks browsing.
- NAVIGATE line still drives shell navigation when requested.
- EN/VI language hint for replies.
- UI skill toolbar in Assist dock.

## Not implemented / limits
- Full page body extraction from WebKit (no TEXT/EVALUATE control command yet); extract/summarize use URL/title (+ optional client excerpt).
- Streaming token responses.
- Automatic Personal AI Hub discovery beyond env URL.
- Certified quality of model answers (depends on provider).
