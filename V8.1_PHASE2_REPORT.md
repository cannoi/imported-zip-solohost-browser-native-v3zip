# SoloHost Browser V8.1.0 — Phase 2 API Gateway

## Done
1. Express mounted as the HTTP application (`express.json`, Phase-2 routes first).
2. `GET /api/browser/parse?url=` validates http(s), runs `ContentExtractor.extract`, returns:
   - success, url, metadata{title,byline,siteName,favicon}, content{clean_html,raw_text,reading_time_minutes}, media{videos[],images[]}
3. `GET /api/health` (+ `/health`) uses `browserGateway.chromiumHealth()` for engine readiness.
4. `browser-gateway.js` rewritten: no frame/canvas WebSocket stream; parseUrl + chromiumHealth exports.
5. AI/Feedback Express mounts retained; legacy routes (static, bookmarks, reader `/view`) kept.

## Not done / limits
- Live Chromium extract over network: depends on `npm install` + Playwright browsers in image — **NOT fully exercised in this packaging environment**.
- Frontend still primarily reader/`/view`; full SPA client for JSON schema is future work.
- Image list in media is only populated when extractor classifies image URLs (Phase 1 focuses on m3u8/mp4).
