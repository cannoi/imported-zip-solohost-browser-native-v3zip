# Install

1. Import this folder as a SoloHost application.
2. Build from local source. Do not use a remote GHCR image.
3. Open the app in the SoloHost web interface on port 8080.

If you only see log lines such as “running on port 8080”, the preview
is attached to process output. Open the published web URL for the app.


The default image installs system Chromium. It does not compile CEF during SoloHost import.
