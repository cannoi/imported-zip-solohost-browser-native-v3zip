# Log analysis & fix

## What the log shows
1. Image pull + extract complete.
2. `Container running.` — app container is alive.
3. Hundreds of identical lines:
   `compose file "C:\Users\Pi\AppData\Roaming\Pi Network\pi-apps\cannoi-solohost-browser\docker-compose.yml" is invalid: ... path not found`

## Root cause
SoloHost **host client** (Windows) polls:

`%AppData%\Pi Network\pi-apps\cannoi-solohost-browser\docker-compose.yml`

If the imported ZIP nested files under `solohost-browser/`, that path has **no** compose file even though the image built from an inner path and the container runs.

## Fix in this package
- Publish ZIP with **project files at ZIP root** (docker-compose.yml next to Dockerfile).
- Keep a copy under `solohost/docker-compose.yml` for docs.

## Cannot fix inside Node app
- Pi Network client path resolution / polling spam.
