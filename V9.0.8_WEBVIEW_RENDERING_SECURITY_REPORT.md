# v9.0.8 — WebView rendering and security report

## Implemented
- Improved HTML/CSS resource routing for common assets, mobile viewport, encoding-aware HTML/CSS decoding and preservation of the original document base URL.
- Added redirect-by-redirect URL validation, a redirect-hop cap, streamed response-size enforcement, IPv4/IPv6 private/reserved address checks, and rejection of embedded URL credentials.
- Added baseline response headers; removed unneeded iframe permissions for camera, microphone, geolocation and payment.
- Updated AI Panel knowledge (English/Vietnamese) to explain the new rendering behavior and remaining compatibility limitations.
- Removed disabled legacy server-engine modules that had no runtime imports in the client-WebView architecture. Kept AI, Feedback, provider engine, browser store, UI, SoloHost packaging files and historical reports.

## Validation
- `npm test`: PASS.
- `node --check` on server, proxy, app adapter and browser UI: PASS.
- Proxy unit regressions: PASS for common resource rewrites, CSS `url()`/`@import`, mobile viewport, local/private IPv4/IPv6 blocking and non-HTTP scheme rejection.
- ZIP inventory and archive integrity: checked during packaging.

## Not completed / residual limitations
- No live-site or SoloHost Docker runtime test was possible in this packaging environment.
- Proxy requests still cannot completely eliminate DNS rebinding without binding the HTTP connection to the exact validated DNS address; DNS is checked before each redirect hop, but the fetch implementation may perform its own resolution.
- Websites relying on dynamic SPA APIs, service workers, WebSockets, DRM, CAPTCHA, browser-managed cookie jars, complex login, or strict CORS may still be incomplete. Those are architectural limitations of an iframe/proxy viewer, not fixed by HTML rewriting alone.
- No native Chromium/WebKit engine was added, by design, to keep Docker lightweight and use the client WebView.

## Preserved
Universal AI/Feedback, provider configuration, app data format, bookmarks/history/tab UI, themes, English/Vietnamese interface, SoloHost config and Docker launch behavior remain in place.
