# WEBVIEW fix

## Problem
WEBVIEW only showed static text — no interactive login form.

## Fix
1. Full-height iframe with sandbox allowing forms/scripts
2. Primary action is real <a target=_blank> (works when popup blocked)
3. Fallback note when X-Frame-Options blocks embed
4. Auth detection less aggressive on long pages with login widgets

## Limits
Google/Facebook set X-Frame-Options: user must use Open page.
True OS WebView is not available inside SoloHost web UI.
