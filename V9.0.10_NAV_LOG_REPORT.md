# v9.0.10 Navigation + Logging

## Root cause (internal links)
With `<base href="https://thanhnien.vn">`, relative `/api/proxy?url=...` became `https://thanhnien.vn/api/proxy?...` → connection failure.

## Fix
proxyOrigin from Host / X-Forwarded-*; all rewritten links and go() use absolute SoloHost origin.

## Logging
lib/app-log.js → data/app.log (same as AI panel Logs)
- proxy.request, proxy.ok, proxy.shell, proxy.fail
- client.navigate, client.proxy_hint via POST /api/logs/client

## Limits remaining
Google/YouTube SPA still not full apps; HTML mode / shells + ↗ for full experience.
